# Digital Clock Project

## Description
A simple and responsive digital clock built using HTML, CSS, and JavaScript. It displays the current time in hours, minutes, and seconds, and updates in real-time. This project is perfect for learning basic DOM manipulation, CSS styling, and JavaScript timing functions.

## Features
- **Real-Time Clock:** Displays the current time and updates every second.
- **AM/PM Format:** Shows time in 12-hour format with AM/PM indicator.
- **Responsive Design:** Works well on desktops, tablets, and mobile devices.
- **Customizable Styling:** Easily change fonts, colors, and layout through CSS.

## Project Structure
- `index.html` — Main HTML file containing the clock structure.
- `style.css` — Styling for the clock interface.
- `script.js` — JavaScript for updating the time dynamically.

## How to Use
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. The digital clock will automatically display the current time.
